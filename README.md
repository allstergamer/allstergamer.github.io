# Allstergamer – Persönliche Website

Dieses Repository enthält meine persönliche Website und verschiedene eigene Webentwicklungsprojekte.

🌐 **Website:** https://allstergamer.github.io/

## 🛠️ Technologien

Der eigene Teil der Website basiert hauptsächlich auf:

* HTML5
* CSS3
* JavaScript
* Git / GitHub
* GitHub Pages

## 🎯 Über das Projekt

Die Website entstand als persönliches Webentwicklungsprojekt und dient dazu, eigene Ideen, Experimente und Projekte online umzusetzen.

Dabei nutze ich die Website unter anderem, um praktische Erfahrungen in folgenden Bereichen zu sammeln:

* Strukturierung von Webseiten mit HTML
* Gestaltung mit CSS
* JavaScript und interaktive Funktionen
* Arbeiten mit Dateien und Assets
* Veröffentlichung von Webprojekten
* Versionsverwaltung mit Git und GitHub

## 📂 Repository

Das Repository enthält neben den aktuellen eigenen Inhalten auch ältere bzw. archivierte Dateien und weitere Inhalte, die historisch mit der Website verbunden sind.

Nicht jeder Bereich des Repositories stellt ein eigenständiges aktuelles Projekt von mir dar.

Für einen Überblick über meine aktuellen eigenen Arbeiten empfiehlt es sich daher, zunächst die öffentlich erreichbare Website und die entsprechend dokumentierten Projekte anzusehen.

## 🚀 Deployment

Die Website wird über **GitHub Pages** veröffentlicht.

Änderungen werden mit Git versioniert und anschließend über GitHub Pages bereitgestellt.

## 📌 Status

Die Website wird laufend weiterentwickelt. Inhalte und Funktionen können sich im Laufe der Zeit ändern.
